# Results

This folder contains regenerable research artifacts:

- `.json` — complete machine-readable recursion trees;
- `.html` — self-contained interactive explorers; and
- `.dot` — optional Graphviz interchange.

Regenerate one instance with `python -m fka run <id>` or the complete library
with `python -m fka run --all`. The filename records the instance and algorithm
variant; backend attribution is embedded in annotated JSON.
