# FK-B reference material

The workstation contains a separate third-party MATLAB FK-B implementation in
`FK-master/`. It is useful for comparison but is not part of this maintained
FK-A package, and its redistribution provenance and license have not been
established. The snapshot therefore remains local and is ignored by Git.

Nothing in `src/fka`, the instance baselines, or the FK-A test suite depends on
that local snapshot.
