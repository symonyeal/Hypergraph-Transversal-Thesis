# Local reading library

This directory is the researcher's local collection of papers and background
reading. The PDFs remain on the workstation but are intentionally ignored by
Git: most are third-party publications whose redistribution rights differ from
this project's GPL source.

The thesis itself is tracked at the repository root because it is the primary
mathematical reference for this implementation. Cite any additional literature
in source comments, tests, or maintained documentation rather than relying on a
local PDF filename.
